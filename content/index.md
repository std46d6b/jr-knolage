# База знаний для Go-интервью

Практическая программа подготовки к техническим интервью для **middle Go developer / E4+**. Курс идёт от языка и баз CS к production-практикам, распределённым системам и system design.

## Как работать с курсом

1. Пройдите модули 01–05 последовательно: это фундамент.
2. Затем чередуйте production-модули 06–13 с регулярной практикой алгоритмов и SQL.
3. Раз в неделю решайте design-задачу с таймером и проводите mock-интервью.
4. Ведите заметки по ошибкам и возвращайтесь к ним по интервальному повторению.

## Критерий готовности

Вы готовы к E4-интервью, если можете написать безопасный конкурентный Go-код, объяснить запрос и план PostgreSQL, спроектировать наблюдаемый сервис с корректной обработкой отказов и аргументировать trade-offs в реальных примерах из опыта.
