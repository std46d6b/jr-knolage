# Инструкции для авторов базы знаний

Этот репозиторий — сайт на **Quartz v5**. Публикуемый Markdown расположен только в `content/`; файлы вне этой папки — конфигурация и исходный код генератора.

## Структура

- `content/index.md` — главная страница сайта.
- `content/course/` — программа подготовки; один модуль — один Markdown-файл.
- `content/templates/` — заготовки страниц. Quartz исключает эту папку из публикации.
- `quartz.config.yaml` — конфигурация сайта. Перед развёртыванием заполнить `configuration.baseUrl`.
- `Dockerfile` — production-сборка статического сайта в nginx.

## Правила создания страницы

1. Создавайте файл в тематической папке с предсказуемым именем: `NN-kebab-case.md`. Для русскоязычного контента оставляйте имя файла на латинице; заголовок страницы пишите по-русски.
2. Каждая публикуемая страница начинается с YAML frontmatter и ровно одного H1.
3. Заполняйте `title`, `description`, `tags`, `status` и `difficulty`. Ставьте `draft: true`, пока заметка не готова к публикации.
4. Используйте `created` и `updated` в формате `YYYY-MM-DD`; не придумывайте даты.
5. Для внутренних ссылок используйте Quartz/Obsidian wiki-links: `[[course/02-go|Go]]`. Для отображаемого текста, отличающегося от имени файла, всегда применяйте `|`.
6. Держите страницу самостоятельной: определение, зачем тема нужна на интервью, минимум E4, углубление, вопросы, практика, ловушки и источники.
7. Не храните секреты, персональные данные, токены, production URL и приватные заметки в `content/`.

## Frontmatter

```yaml
---
title: Название темы
description: Одно предложение о содержании и ценности страницы.
tags:
  - go
  - interview
status: draft # draft | in-progress | complete
difficulty: e4 # foundation | e4 | e5
created: 2026-09-21
updated: 2026-09-21
aliases:
  - Альтернативное название
draft: false
---
```

Поле `aliases` необязательно. Для индексных страниц добавляйте `cssclasses` только при реальной потребности в кастомном оформлении.

## Заголовки и блоки

- `#` — только заголовок страницы; не повторяйте его в теле.
- `##` — основные разделы; `###` — детали. Не перескакивайте через уровни.
- Формулируйте заголовки как тему, а не «Разное» или «Полезное».
- Используйте короткие абзацы, списки для перечней, таблицы только для сопоставления.
- Код всегда в fenced-блоке с языком: `go`, `sql`, `yaml`, `bash`, `text`.
- Для задач применяйте чек-листы `- [ ]`.
- Для формул используйте KaTeX: `$inline$` и `$$block$$`.

## Стандартные разделы учебной заметки

```markdown
# <Тема>

## Зачем это на интервью

## Минимум для E4

## Углубление для E5/Senior

## Ключевые понятия

## Типовые вопросы

## Практика

## Частые ошибки и ловушки

## Связанные темы

## Источники
```

Не добавляйте пустые разделы: если раздел пока не готов, поставьте заметке `draft: true` или оставьте явный TODO в разделе «Практика».

## Проверка перед коммитом/деплоем

```bash
npm ci
npx quartz plugin install
npx quartz build
# или production-образ:
docker build -t go-interview-kb .
docker run --rm -p 8080:8080 go-interview-kb
```

Сборка должна завершаться без битых внутренних ссылок и создавать `public/`. В Docker-образе сайт доступен на `http://localhost:8080`.
